Windows

微软商店安装（推荐）

在 Microsoft Store 搜索「ChatGPT」或「OpenAI Codex」，安装由 OpenAI 发布的官方应用。新版桌面端集成 Chat、Work 与 Codex。

  1. 打开系统自带的 Microsoft Store。
  2. 搜索 ChatGPT（发布者 OpenAI），或打开下方商店详情页。
  3. 点击「获取 / 安装」，等待 .msix 完成。
  4. 开始菜单找到 ChatGPT，用 ChatGPT 账号登录。
  5. 在应用内切换到 Codex 视图即可编程。

⚠️ 请勿使用会改写 API 地址的第三方「Codex 安装器」

  • 部分来路不明的 exe / 脚本会悄悄改写 API Endpoint、注入代理或窃取密钥。
  • 优先使用 Microsoft Store 或 OpenAI / chatgpt.com 官方页面。
  • 若必须配置国内中转，请按我们完整教程中的 cc-switch 步骤操作，不要运行未知一键包。
  • 安装后核对：发布者为 OpenAI；商店包为 Microsoft 签名分发。

精简版 Windows / 无商店环境备选

部分企业镜像禁用 Microsoft Store。可先确认 IT 策略是否允许商店应用；若仅缺 Store 客户端，可尝试用管理员 PowerShell 从商店源安装（需网络与微软账号策略允许）：

# 示例：通过 winget 从 msstore 安装（包 ID 以商店页为准，安装前请核验）
winget install --id 9PLM9XGG6VKS --source msstore --accept-package-agreements --accept-source-agreements

若 winget / 商店均不可用，请优先阅读完整教程中的 Windows 安装说明，或联系 QQ 客服确认当前推荐方式。不要下载未签名的「绿色破解版」。
